# DEELX 正規表現エンジン

ヘッダファイル `deelx.h` ひとつだけで動く、C++ のバックトラック型正規表現エンジンです。外部ライブラリは使いません。Visual C++ 6.0 から最近の g++・clang・MSVC までビルドできます。

## 対応している正規表現

### 文字

| 構文 | 意味 |
|---|---|
| `a` `1` `あ` など | その文字そのもの |
| `\.` `\*` `\\` など | 記号の前に `\` を付けると、その記号そのもの |
| `\t` `\n` `\r` `\f` `\v` `\a` `\e` | タブ・改行(LF)・復帰(CR)・改ページ・垂直タブ・ベル・エスケープ |
| `\xHH` | 16進2桁で表す文字（`\x41` は `A`） |
| `\uHHHH` | 16進4桁で表す文字（`あ` は「あ」） |
| `\x{...}` `\u{...}` | 16進で表す文字。U+10000 以上も書けます（`\u{1F600}`） |
| `\Q...\E` | 間の文字列を記号も含めてそのまま扱う（`\Qa.b\E` は `a.b` だけに一致） |
| `\U...\E` `\L...\E` | 間の文字列を大文字・小文字に変換してから、そのまま扱う |

### 文字クラス

| 構文 | 意味 |
|---|---|
| `.` | 改行以外の任意の1文字（`SINGLELINE` では改行にも一致） |
| `[abc]` | a・b・c のどれか1文字 |
| `[a-z]` | a から z までのどれか1文字 |
| `[^abc]` | a・b・c 以外の1文字 |
| `\d` `\D` | 数字 / 数字以外 |
| `\w` `\W` | 単語の文字（英数字と `_`） / それ以外 |
| `\s` `\S` | 空白文字（スペース・タブ・改行など） / それ以外 |
| `\h` `\H` | 横方向の空白（スペース・タブ。CRegexpW では全角スペースなども含む） / それ以外 |
| `[[:alpha:]]` | POSIX クラス。`alnum` `alpha` `ascii` `blank` `cntrl` `digit` `graph` `lower` `print` `punct` `space` `upper` `xdigit` が使えます |
| `[[:^alpha:]]` | POSIX クラスの否定 |

`\d` `\w` `\s` は `[...]` の中でも使えます（`[\d_]`）。`\d` `\w` `\s` `\b` は通常 ASCII の範囲だけを対象にします。`UNICODE_MODE` を指定すると Unicode 全体が対象になります（後述）。

### Unicode プロパティ

| 構文 | 意味 |
|---|---|
| `\p{L}` `\pL` | 一般カテゴリが L（文字）の1文字 |
| `\p{Lu}` | 一般カテゴリが Lu（大文字）の1文字。2文字のカテゴリ名はすべて使えます（`Ll` `Nd` `Zs` `So` `Cn` など） |
| `\P{L}` `\p{^L}` | 一般カテゴリが L 以外の1文字 |
| `\p{L&}` `\p{LC}` | 大文字・小文字・タイトルケースの文字 |
| `\p{Any}` / `\p{Assigned}` / `\p{ASCII}` | 任意の文字 / 割り当て済みの文字 / U+0000〜U+007F |
| `\p{White_Space}` `\p{Space}` | Unicode の空白文字（全角スペース、U+2028 なども含む） |
| `\p{Word}` | Unicode の単語の文字（`UNICODE_MODE` の `\w` と同じ） |
| `\p{Xan}` `\p{Xwd}` `\p{Xsp}` `\p{Xps}` | PCRE 互換：文字と数字 / 文字・数字・`_` / 空白 / 空白 |

`\p{...}` は `UNICODE_MODE` なしでも使えます。`[...]` の中にも書けます（`[\p{Lu}\d]`）。スクリプト（`\p{Hiragana}` など）やブロックには対応していません。知らない名前はどの文字にも一致しません。

### 位置

| 構文 | 意味 |
|---|---|
| `^` `$` | 文字列の先頭 / 末尾（`MULTILINE` では行頭 / 行末） |
| `\A` | 文字列の先頭 |
| `\Z` | 文字列の末尾。末尾の改行の直前にも一致 |
| `\z` | 文字列の末尾 |
| `\b` `\B` | 単語の境界 / 単語の境界以外 |
| `\G` | 前回の一致が終わった位置（`GLOBAL` 指定時のみ） |
| `\K` | 一致の開始位置をここにする。それより前は条件として調べるだけで、一致には含めません（`foo=\Kbar` は `foo=bar` の `bar` に一致） |

### 量指定子

| 構文 | 意味 |
|---|---|
| `*` `+` `?` | 0回以上 / 1回以上 / 0回か1回 |
| `{n}` `{n,}` `{n,m}` | n回 / n回以上 / n回以上m回以下 |
| `*?` `+?` `??` `{n,m}?` | 最短一致（なるべく少なく繰り返す） |
| `*+` `++` `?+` `{n,m}+` | 強欲（繰り返した分を手放さない。バックトラックしない） |

量指定子として読めない `{` は普通の文字です（`a{,3}` は文字列 `a{,3}` に一致）。

### グループと参照

| 構文 | 意味 |
|---|---|
| `(...)` | キャプチャするグループ（左から 1, 2, ... と番号が付く） |
| `(?:...)` | キャプチャしないグループ |
| `(?<name>...)` `(?'name'...)` `(?P<name>...)` | 名前付きグループ |
| `(?<2>...)` | 番号を指定したグループ |
| `(?\|...\|...)` | ブランチリセット。選択肢ごとにグループ番号を同じ番号から振り直す |
| `(?>...)` | アトミックグループ（いったん一致したら、中でバックトラックしない） |
| `\1` `\2` ... | 後方参照（その番号のグループが一致した文字列） |
| `\k<name>` `\k'name'` `\g<name>` `\g<1>` `\g1` | 名前・番号による後方参照 |
| `(?#...)` | コメント |

### 先読み・後読み・条件・再帰

| 構文 | 意味 |
|---|---|
| `(?=...)` `(?!...)` | 肯定先読み / 否定先読み |
| `(?<=...)` `(?<!...)` | 肯定後読み / 否定後読み。中身は可変長でも構いません（`(?<=ab+)c`） |
| `(?(1)yes\|no)` `(?(name)yes\|no)` | グループが一致していれば yes、そうでなければ no |
| `(?(?=...)yes\|no)` | 先読みなどの条件が成り立てば yes、そうでなければ no |
| `(?R)` `(?0)` | パターン全体を再帰的に呼び出す |
| `(?1)` `(?R1)` `(?R<name>)` `(?R'name')` | 指定したグループを再帰的に呼び出す（`^(\((?1)*\))$` は対応の取れた括弧に一致） |
| `(?<name-other>...)` `(?<-other>...)` | .NET 互換のバランシンググループ |

### オプション

コンパイル時のフラグで指定するほか、パターンの中でも切り替えられます。`(?i)` はその位置から、そのグループの終わりまで有効です。`(?i:...)` は括弧の中だけ、`(?-i)` は解除です。`(?im-sx)` のようにまとめても書けます。

| フラグ | パターン内 | 意味 |
|---|---|---|
| `IGNORECASE` | `(?i)` | 大文字と小文字を区別しない |
| `MULTILINE` | `(?m)` | `^` `$` を行頭・行末に一致させる |
| `SINGLELINE` | `(?s)` | `.` を改行にも一致させる |
| `EXTENDED` | `(?x)` | パターン中の空白を無視し、`#` から行末までをコメントにする（`[...]` の中は除く） |
| `GLOBAL` | `(?g)` | `\G` を有効にする |
| `RIGHTTOLEFT` | なし | 文字列の右から左へ検索する |
| `UNICODE_MODE` | `(?u)` | CRegexpW で Unicode を考慮する（下記） |

`UNICODE_MODE` を指定すると、CRegexpW の挙動が次のように変わります。CRegexpA では無視されます。
- `\w` `\d` `\s` `\b` が Unicode 全体を対象にします（`\d` は全角数字にも一致します）。
- `IGNORECASE` が Unicode の case folding に従います（`д` と `Д`、`σ` `ς` `Σ` も同じ文字として扱います）。
- サロゲートペア（絵文字など U+10000 以上の文字）を1文字として扱います。`.` も `[^a]` も、絵文字1文字に一致します。

### 置換文字列（`Replace`）

| 構文 | 意味 |
|---|---|
| `$1` `$2` ... | その番号のグループが一致した文字列 |
| `${name}` | 名前付きグループが一致した文字列 |
| `$&` | 一致した文字列全体 |
| `` $` `` `$'` | 一致した部分より前 / 後ろの文字列 |
| `$+` | 最後に一致したグループ |
| `$_` | 元の文字列全体 |
| `$$` | `$` という文字 |

## 使い方

`deelx.h` をインクルードするだけで使えます。MSVC では例外処理を有効にしてください（`/GX` または `/EHsc`）。メモリ確保に失敗すると `std::bad_alloc` を投げるためです。

```cpp
#include "deelx.h"

// 最初の一致を探す
CRegexpA regexp("(\\d+)-(?<tail>\\d+)");
MatchResult result = regexp.Match("tel 03-1234");

if( result.IsMatched() )
{
	int start = result.GetStart();             // 一致の開始位置 (4)
	int end   = result.GetEnd();               // 一致の終了位置 (11)
	int g1    = result.GetGroupStart(1);       // グループ1の開始位置
	int tail  = regexp.GetNamedGroupNumber("tail");
	int t     = result.GetGroupStart(tail);    // 名前付きグループの開始位置
}

// 文字列全体が一致するか
int whole = regexp.MatchExact("03-1234").IsMatched();

// すべての一致を順に取り出す
CContext * pContext = regexp.PrepareMatch("1-2 3-4");
for( result = regexp.Match(pContext); result.IsMatched(); result = regexp.Match(pContext) )
{
	// result.GetStart(), result.GetEnd() ...
}
regexp.ReleaseContext(pContext);

// 置換（すべて置き換える）。戻り値は ReleaseString で解放する
char * replaced = regexp.Replace("tel 03-1234", "$2-$1");
// replaced は "tel 1234-03"
CRegexpA::ReleaseString(replaced);
```

- **フラグ**: `CRegexpA regexp("abc", IGNORECASE | MULTILINE);` のように、2番目の引数で指定します。
- **文字の型**: `CRegexpA` は `char` の文字列、`CRegexpW` は `unsigned short`（UTF-16）の文字列を扱います。`CRegexpA` はマルチバイト文字（Shift_JIS・UTF-8 など）を認識しません。1バイトずつ処理するので、Shift_JIS の2バイト目が `\` などの ASCII 文字に一致することがあります。日本語を扱うときは UTF-16 に変換して `CRegexpW` を使ってください。`CRegexpT<wchar_t>` のように、ほかの文字型でも使えます。
- **長さ指定**: `Match(text, length, start)` のように長さを渡せば、NUL 終端でない文字列も扱えます。
- **スレッド**: コンパイル済みの正規表現は、複数のスレッドから同時に使えます。`CContext` はスレッドごとに用意してください。
- **ステップ上限**: バックトラック型のため、`(.*a){12}c` のようなパターンは入力によって指数時間かかります。これを防ぐため、1回の `Match()`・`MatchExact()` あたりのバックトラック回数に、**デフォルトで上限**がかかっています。上限は `1000000 + 256 × 入力の長さ` で、通常のパターン（1文字あたり 1〜5 ステップ程度）には十分な余裕があります。ただし、`\w+@` を単語文字だけが何万文字も続く入力に当てるような、二乗オーダーのパターンも打ち切られます。上限を超えると不一致として返り、`result.IsStepLimitExceeded()` が真になります。不一致が本当に「見つからなかった」のか「打ち切られた」のかは、これで区別してください。`regexp.SetStepLimit(n);` で上限を固定値に、`regexp.SetStepLimit(0);` で無制限に、負の値で自動に戻せます。
- **不正なパターン**: エラーとしては報告されません。何らかの解釈でコンパイルされます（たとえば `a**` の2つ目の `*` は普通の文字になります）。

## テスト

`deelx_test.cpp` が回帰テストです。開発者向けの注意事項も、このファイルの冒頭にまとめてあります。

```
g++ -Wall -Wextra -o deelx_test deelx_test.cpp && ./deelx_test
cl /nologo /W3 /GX deelx_test.cpp && deelx_test.exe
```

`deelx.h` 末尾の Unicode の表は、`tools/gen_unicode_tables.py` で Unicode Character Database から生成しています。
